## 🎯 Why Players Worldwide Use ViceRoute

1. **🌍 100% Free, Fan-Made & Community-Driven (Zero Paywalls):**
   - Unlimited location checkoffs (`0/125+`), JSON save export/import backups, and custom community pins.
   - **In-App Community Pin Builder (`🤝 + Add Spot / Build Together`):** Tap anywhere on the State of Leonida map to pick exact `X, Y` coordinates, add a custom pin immediately to your map, and 1-click submit it to the worldwide GitHub map!
2. **🧭 "What's Around Me" Nearby GPS Explorer & AI Route Optimizer:**
   - Drag your pulsing blue Console GPS marker anywhere on Leonida—or tap any of the **12 Region Fast-Travel buttons**—to sort all 125+ spots by **what is closest to you right now (`~140m away`)**.
   - Click **`AUTO-PLOT FASTEST 100% ROUTE`** to calculate the shortest driving path across all remaining uncollected stops, complete with a **Hands-Free Voice Co-Pilot**.
3. **🗺 1:1 State of Leonida Island Geometry & 3 Visual Modes:**
   - Built directly over the high-contrast State of Leonida map (`leonida-map.jpg`) with switchable **Clean GTA 6 Map**, **Retro '86 Synth Grid**, and **Cyber Radar** themes.
4. **🚔 Tactical Radar Zones, Escape Mod Shops & Lucia/Jason Heist Planner:**
   - Toggle **6-Star Restricted Airspace**, **Evergrass Alligator Territories**, and **Pay 'n' Spray / Rideout Customs Escape Garages (`🔧`)**.
   - Plan **Lucia & Jason** robbery runs and plot an all-heists money route across Leonida.
5. **📻 Zero-Dependency Procedural Web Audio Synthwave Radio & ViceGuessr:**
   - Built-in Web Audio API synthesizer featuring 4 playable stations (*Flash FM, Vice Synth 106.9, Emotion 98.3, Fever 105 Electro*), classic GTA SFX, **Leonida ViceFeed** social cards, and a **5-Round ViceGuessr Geo-Recon minigame**.

## 🛠️ How the Community Can Build on It

This project is purposefully built as a **zero-build, single-page application (`index.html` + `leonida-map.jpg` + `manifest.json` + `sw.js`)** so any gamer or developer worldwide can fork, edit, and run it in seconds without complicated build toolchains.

### 1. Add a Spot Directly on the Live Map (No Coding Required)
Click **`🤝 + ADD SPOT / BUILD TOGETHER`** inside the web app, click **`🎯 Pick X/Y on Map`**, fill out your discovery, and click **`🚀 SUBMIT TO WORLDWIDE GITHUB MAP`**.

### 2. Run Locally or Submit a Pull Request
```bash
git clone https://github.com/lociAI/gta6-leonida-community-map.git
cd gta6-leonida-community-map
python3 -m http.server 8080
```
Open **`http://localhost:8080`** in your browser. All map spots live in the `LOCATIONS` array inside [`index.html`](./index.html) using a `2000 × 2000` coordinate grid (`x: 0..2000` West-to-East, `y: 0..2000` South-to-North).
